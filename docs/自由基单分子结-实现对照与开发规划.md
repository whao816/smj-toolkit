## 2. 与源文档逐条一致的部分

1. **`spin` 只能 `none`/`collinear`**（§6.4）。`spin non-collinear`、三分量 `initial_moment` 一律不用；实现里 `SpinState.spin` 只有两个取值。
2. **`fixed_spin_moment` 的口径**（§6.1）：约束的是 `N↑−N↓=2M_S`，常见双重态最高分量是 1 而不是多重度 2。`smj/spin.py` 正是 `multiplicity−1`，且 notes 里反复强调"不要与多重度混同"。
3. **`initial_moment` vs `fixed_spin_moment`**（§6.1）：前者只是初始密度，后者才是约束。代码里两条路径分开写，开壳层缺 initial moment 时 notes 明确提示"可能收敛到非磁解"。
4. **自旋极化 SCF 不写 `mos.aims`，改 `alpha.aims`/`beta.aims`**（§3.2）：`aims_scf.collect`、`remote.download`（optional head）、`aitranss_te._spin_nsaos` 三处都按这条处理。
5. **tcontrol 必须换成 `$uhfmo_alpha`/`$uhfmo_beta`**（§6.3）：`aitranss_te._patch_tcontrol` 行扫描替换，并在 summary/notes 留档。
6. **`TE.dat` 的能量口径**（§6.6）：第 1 列 Ha、第 2 列 eV 相对 E_F、第 3/4 列 α/β。`transport.energy_window` 用 eV 相对 E_F 配置，prepare 时用 `aims_scf/aims.out` 的 efermi 平移到 Ha 绝对，再写 `$ener/$estep/$eend`；缺 efermi 直接 StageBlocked。1 eV = 0.0367493 Ha 的换算只在代码里出现一次。
7. **六个表面索引每侧三个原子号**（§6.6）：`make_tcontrol` 从 `electrode_metadata.json` 的 `left/right_surface_indices` 取，正是 `-lsurc/-lsurx/-lsury` 各一个原子的写法。
8. **`G/G0=(T↑+T↓)/2` 与 `G0=2e²/h`**（§8.1）：`landauer.py` 的 docstring 与 `landauer_spin.py` 的 `g_over_g0_total=0.5*(L0α+L0β)` 一致；文档明确反对"再乘一个 2"。
9. **自旋极化率 P(E)**（§8.6）：`analyze_te_spin` 输出 `spin_polarization_at_ef` 与 `spin_polarization_L0`，图里以 % 标注，且同时给出总电导，避免"接近 100% 但电导近零"的误读。
10. **AITRANSS 的 `$ecp` 与 SCF 的 ECP 不是一回事**（§6.3）：模板里是 `$ecp off`，我们也不在文档里把 `$ecp` 解释成赝势。

## 3. 口径不同或需要特别说明的部分

### 3.1 ⛔ 整结电荷 `molecule.charge` ≠ 分子片段电荷

源文档 §4.1 强调：`q_tot`、分子片段 `q_mol`、局域自旋是三个量；中性结里分子也可能带非整数电荷；`q_tot=0/±1` 的原始总能不能直接排序。

本项目当前的设计是：`molecule.charge` 直接写进 FHI-aims 的 `charge`（整个结）。对 TTF⁺ 这类"分子本身是阳离子"的体系这是合理的显式设定，但对"中性分子放在电极间、接触后电荷转移"的体系，这个键会被误读成"分子带整数电荷"。

**建议**（不改现有语义，只加说明与证据）：
- 在 `smj-计算流程梳理.md` 的 `molecule.charge` 行注明"这是整个模型的电荷，不是分子片段电荷"；
- 后续在 `junction_analyze` 里增加分区电荷报告（Mulliken/Hirshfeld 按 atom list 求和），让"片段电荷"成为输出而不是输入假设。

### 3.2 ⚠️ `fixed_spin_moment` 固定的是整个结

源文档 §6.1 明确警告：除非有明确的约束态模型，**不应永久固定整个结的自旋来"保证自由基存在"；应比较解除约束后的解**。

本项目的 Phase 2 恰恰是"用户显式要求固定总自旋"，并且 TTF 实测把文档的担心演示了出来：总自旋 `N↑−N↓=1.00` 保持，但分子原子 1–14 的 Mulliken 自旋转角只有 0.0055 μB，未成对电子基本离域进了 Au 团簇。

**建议**：
- 配置层增加 `molecule.fixed_spin_moment: auto|none`（`none` = 只给 `initial_moment` 初猜，不加强制约束）；默认保持 `auto` 以兼容现有 run；
- 在 open-shell run 的 `smj review` 或 report 里强制提示："本结果来自固定总自旋的解，需与 release 解对照"；
- 把 TTF 的"总磁矩 1 μB、分子 0.005 μB"作为文档里的教学案例，写进 §已知限制。

**现状（2026-11-19 已实现前半）**：配置项落地为 `molecule.fixed_spin_moment: true|false`（默认 `true`，`false` 时不写 `fixed_spin_moment` 行、只留 `spin collinear` + 逐原子初猜）；`smj/spin.py` 的 `SpinState.fix_spin_moment` 统一 tip_relax/aims_scf。review/report 的强制提示与对照 run 尚未做（见 P2-7）。

### 3.3 ⚠️ 结级 `initial_moment` 的粒度太粗

`molecule_opt` 已经把 `molecule.initial_moments` 写成每原子 `initial_moment`；但 `aims_tip_relax`/`aims_scf` 只写**全体原子统一**的 `default_initial_moment 0.1`。源文档 §6.6 的建议是：`default_initial_moment 0.0`，在自由基原子上给 `initial_moment`，BS 候选给相反局域初猜。

结几何里分子原子索引 1..n_mol 是不变的（tip 追加在 n_mol+1、n_mol+2；电极继续追加），所以这个映射可以直接做。

**现状（2026-11-19 已实现）**：`smj/spin.py` 的 `map_molecule_moments` 把分子坐标系序号映射到结几何（`strip_thiol_h` 删掉的锚定 S–H 会让后面的原子左移，按 `removed_h_indices` 校正；指向被删氢会报错）；`write_initial_moments` 在对应 `atom` 行后写 `initial_moment`，存在逐原子初猜时不再写 `default_initial_moment`；tip_relax 与 aims_scf 两处都已接线，notes/summary 记录映射结果。

**建议**：`aims_tip_relax`/`aims_scf` 读 `molecule.initial_moments`，按索引写到 geometry.in 的对应 atom 行；`default_initial_moment` 降到 0.0（或保留 0.1 作为"未指定时的兜底"，由配置开关选）。

### 3.4 ⚠️ 产物里没有自旋密度/Hirshfeld

源文档 §6.6 点明：`output cube spin_density` 是文档化的共线自旋输出，Hirshfeld 需显式请求、不会默认打印。当前 `control_scf.in` 只有 `output aitranss` 与 `output mulliken`。

**已核实**：项目所用 FHI-aims 221103 二进制里能查到 `hirshfeld`（171 次）与 `spin_density`（7 次）字符串，关键字存在；但是否与 aitranss 输出/当前 SCF 设置组合无冲突，需一次小体系实测确认。

**建议**（低成本、可选）：加配置 `transport.extra_outputs: [hirshfeld, spin_density]`，prepare 时往 control.in 追加对应 `output` 行；默认关闭，避免所有 run 产物变重。自旋密度对"自由基是否存活"是第一手证据，值得做。

**现状（2026-11-20 已实现 P1-5，关键字仍待实测）**：配置与产物链已接线——
`transport.extra_outputs` 走白名单（写错即 `ConfigError`），`aims_scf` 的 `control.in` 追加
`output hirshfeld` / `output cube spin_density`；collect 核验 `spin_density.cube` 非空、
`aims.out` 确有 Hirshfeld 段（扣掉 `vdw_correction_hirshfeld` 回显），请求了没产出就拒绝
`collected`；闭壳层要 `spin_density` 直接 `StageError`。**但**：`output cube spin_density`
与 `output hirshfeld` 的组合在 221103 上仍未实测，首次启用请先用小体系确认 FHI-aims
接受这两个关键字、且 aitranss 仍能读到 omat/mos（`tests/test_extra_outputs.py` 只锁
接线与核验，不替代实测）。

### 3.5 ⚠️ `$self_energy file=self.energy.in` 是固定写法

模板里 tcontrol 始终带 `$self_energy file=self.energy.in`。源文档 §6.3 提醒：一旦给了自能文件，边界区域/泄漏率相关的其它设置不再生效，"改了参数却没变化"很可能是还在读旧的自能文件。

本项目从不暴露泄漏率参数，所以这个风险目前是"文档化"而非"功能"问题。**建议**在流程文档的 aitranss_te 段写明：本包只用 Au 库团簇 + 默认吸收边界，所有 run 使用独立目录，`self.energy.in` 随阶段目录隔离。

### 3.6 ⚠️ AITRANSS 的构建形态

本项目环境里 aitranss 是 `aitranss.071813.openmp.ifx2025.3.x`（OpenMP 构建）。源文档 §6.3 引官方手册 [M8]：多线程版本曾出现错误结果，建议串行版本。

**建议**：在 run 的环境说明里记录二进制路径与构建；如集群上有串行版本，生产 run 优先串行；至少用一个已知 Au 算例核对 OpenMP 与串行输出一致。

### 3.7 ⚠️ 主指标是双通道均值，spin 块只进 results.json

`report.md` 的 transport 摘要键表（`report.py:328` 附近）只有 `L0/L1/L2/log10_G_over_G0_like/S/k_e/ZT_e/fermi_nearest/max_transmission`，没有 spin 块；`smj review` 也不读 multiplicity。

**建议**：
- `report.py` 的 transport 段在 `junction_analyze/results.json` 含 `spin` 时追加一小节（Tα/Tβ(EF)、P(EF)、P(L0)），并在图注/正文里注明"G、S 仍为双通道均值"；
- `review.py` 对 `multiplicity>1` 加一条 WARN（不是 error）：现有判据族没有自由基条目，`g_in_theory_band` 等对开壳层体系仅作参考。

**现状（2026-11-20 已实现 P0）**：
- 新增 `src/smj/spin_summary.py`：把 `run_spec` 的 molecule 块（多重度/电荷/是否钉住总自旋）与 `results.json` 的 `spin` 块压成同一份展示字段，`report`/`review` 共用一套口径（`SPIN_CAVEAT`、`FIXED_CONSTRAINT_CAVEAT`、`SINGLE_CHANNEL_CAVEAT`）。
- `report.md`：§2 输入摘要新增「电荷 / 多重度」与开壳层的「总自旋约束」；§4 末尾在 `results.json` 含 `spin` 时输出 `### 4.1 自旋通道（开壳层）`（通道数、Tα/Tβ(E_F)、P(E_F)、P(L0)、Gα/Gβ/G_total），并显式注明总 G/S 仍是双通道均值。manifest 的 `transport.spin` 保留同一份字段供程序读取。
- `smj review`：`multiplicity>1` 记 warning `open_shell_uncalibrated`（判据族未校准），钉住总自旋时附 info `spin_fixed_constraint`；开壳层却只有单列 TE.dat 记 warning `spin_channels_missing`；旧 run 缺 multiplicity 但有两列谱记 info `spin_channels_undeclared`。这些 warning 把 `review.status` 降为 `warning`（不阻断），`review.json` 新增 `spin` 块。

### 3.8 ⚠️ 判据族不含自由基

`criteria.py` 的 `EXPECTED_RESONANCE` 只登记 BDT/吡啶/烷链/2CN 等闭壳层参照；旧实现在未登记族上按"全部判据适用"处理（fail-open），对自由基是过度断言。**建议**：把 `family` 扩展为可声明"开壳层/未校准"，让 review 的物理判定显式降级为 `inconclusive` 而不是 `passed`。

**现状（2026-11-20 已实现）**：`criteria.applies(criterion, family, *, open_shell=...)` ——
开壳层（`multiplicity > 1`）或族未知时，带 `applies_to` 的判据（`g_in_theory_band`、
`seebeck_sign`）一律 `applicable=False` 只记录；`evaluate_run_criteria` /
`validate_junction_run` 新增 `multiplicity`，`report.build_manifest` 从 `run_spec` 取族、
从输入摘要取多重度。实测 `runs/ttf-release` 的 `physics_verdict` 由 `passed` 变
`inconclusive`（`no_applicable_gate`）。`EXPECTED_RESONANCE` 仍是闭壳层族表：跨族闸门
需要每族自己的 band 与文献，属于 §6 P3 的"判据族扩展"。

## 5. 实测对照：TTF⁺ / Au(111)

run：`runs/ttf-cation`（molecule_opt → aims_tip_relax → electrode_build → aims_scf → aitranss_te → junction_analyze）。

| 观测量 | 实测 | 与源文档的关系 |
|---|---|---|
| SCF 总自旋 | `N↑−N↓=1.00` 全程保持 | §6.1 约束生效，但只证明"约束被满足" |
| 分子局域自旋（Mulliken 投影，原子 1–14） | 0.0055 μB | 正中 §5.2："总磁矩 ≈1 μB 不能保证自旋属于目标分子" |
| α−β 本征值最大分裂 | 19.9 meV（E_F 附近 top-18 平均 0.3 meV） | 双通道未塌缩，但分裂很小 |
| Tα/Tβ 逐点差 | max\|ΔT\|=0.00235，P(E_F)=−0.23% | §8.6：极化极弱，且总电导 0.234 G0，不是"近 100% 但电导近零"的反例 |
| 电极/输运轴 | `smj review` 报 `表面索引落在输运轴(y)错误一侧: [82]` | §5.1："接触方式/构型必须覆盖多候选"，单构型不足以支撑结论 |

**结论**：现有链能给出"结级共线自旋 + 双通道透射 + P(E)"的**基线**；但"自由基在结中是否存活"的证据链（自旋密度、分组投影、接触集合）仍不完整，不能仅凭总磁矩下结论。

### 5.1 fixed vs release 对照（2026-11-19，同一 88 原子几何、同一边界条件）

两套 run 由 `runs/ttf-cation` 复制而来：`runs/ttf-fixed`（`fixed_spin_moment: true`，默认）与 `runs/ttf-release`（`fixed_spin_moment: false`，只保留 `spin collinear` + 逐原子 `initial_moment`）。两套都从相同的分子初猜（原子 4/5 各 0.5 μB）出发，展宽/混合参数同为 `gaussian 0.05` / `charge_mix_param 0.05`。

| 观测量 | fixed（钉住 S=1/2） | release（不钉） |
|---|---|---|
| SCF | 收敛，85 迭代 | 收敛，111 迭代 |
| 总能 / Ha | −1458508.64393202 | −1458508.64378948 |
| SCF 末态 `N↑−N↓` | 1.0002 μB | −0.0012 μB（≈0） |
| 分子 1–14 自旋 | 0.00546 μB | −0.00010 μB |
| tip 15/16 自旋 | 0.00512 μB | −0.00008 μB |
| 电极 17–88 自旋 | 0.98961 μB | −0.00103 μB |
| 整体 gap | 8.97 meV | 0.89 meV |
| E_F / 化学势 | μ↑=−6.45736 eV、μ↓=−6.45413 eV（劈裂 3.22 meV） | 单一 Fermi 能 −6.45583 eV（非极化输出） |

- **总能差**：`E(release) − E(fixed) = +0.00014254 Ha = +3.88 meV`，即钉住 S=1/2 的解反而略低。约束没有付出能量代价，但这只是同一个初猜下的两个收敛解，不能据此断言 fixed 就是全局基态。
- **两种解都没有把自旋留在分子上**：fixed 解的 1 μB 有 98.9% 在电极、0.55% 在分子；release 解直接收敛到 S≈0。因此"TTF⁺ 自由基在结中存活"在本几何下不成立——不是初猜没给对，而是离域/屏蔽把分子局域磁矩抹掉了。
- **release 解几乎无能隙**（0.89 meV），说明去掉约束后体系更接近闭壳层金属态；fixed 解的 8.97 meV 来自交换劈裂，属于同一几何下的另一个近简并解。
- 两解仅差 3.9 meV，对应极小的自旋刚度；在 PBE/light + TS-vdW 下，这类"自由基 + 金团簇"体系的自旋态对泛函/展宽/接触构型敏感，后续若要下结论需覆盖接触候选与泛函/展宽组合（见 §6 P2-9）。
- **接触构型复核（2026-11-20）**：用 `tip_direction: lone_pair` 重建同一体系（`runs/ttf-lone-pair`，`smj review` 通过，S6–Au15 / S10–Au16 均 2.36 Å、两接触共线），同样跑 fixed/release：fixed 82 迭代、release 104 迭代，两者总能差仍为 **+3.88 meV**；fixed 解的 1 μB 仍是 98.9% 在电极、分子 0.00524 μB；release 解仍是 S≈0（分子 −0.00008 μB），gap 0.82 meV。两个几何的 fixed 总能只差 4.5 meV。结论对接触构型不敏感——"总磁矩保持但分子局域自由基被淬灭"是这条链在 PBE 下的稳定表现，而不是某一种贴装方式的偶然。
- **Hirshfeld 分区复核（2026-11-21，批次 A S1）**：`aims_scf` 现在把 FHI-aims 的 `Hirshfeld spin moment` 逐原子解析进 `spin_partition.json`，报告 §4.1 显示"自旋分布"表。对 `runs/ttf-cation/ttf-cation` 实测：总 1.0000 μB；分子 1–14 = 0.0056 μB（0.56%）、tip 15/16 = 0.0063 μB、电极 17–88 = 0.9881 μB——与上表 Mulliken 投影（0.00546 / 0.00512 / 0.98961）一致到 1e-3，两个独立分区口径都指向"自旋在电极侧"。`smj review` 对分子份额 <1% 的开壳层 run 记 `spin_localized_off_molecule`（info，只陈述数字）。
