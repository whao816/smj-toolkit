# AutoSMJ 的 SIESTA 零偏压电子输运路线

AutoSMJ 已实现从分子 XYZ 到零偏压电导的六阶段路线。集群作业加载 `siesta/5.4.2-gpu-netcdf`。2026-11-27 已在 gpu1 上用 bpy/ppd 两套平坦 Au(111) 接触完成端到端验证：六阶段作业全部 `collected`，`smj report` 生成可追溯的 `report.md`。2026-11-28 补横向 k 与屏蔽证据：bpy 3×3→5×5 与 5×5→7×7 均未达 1% 判据（+22.9%/+5.6%），判定 `failed`；ppd 3×3→5×5 为 −0.7%，判定 `passed`；两套 5×5 的电极屏蔽均 `passed`。详见[首轮验证记录](validation-siesta-2026-11-27.md)与[k 点验证记录](validation-siesta-kconv-2026-11-28.md)。

## 运行方法

安装 `pip install -e ".[siesta]"`，从[平面 Au(111) 接触配置](../demo/siesta-au111/smj.yaml)开始。示例引用仓库内的薁二硫醇坐标，按两端巯基去氢组装。给每个元素指定可读取的 PBE 赝势文件和基组。示例的晶胞尺寸、结合位点和采样密度是起始设置，具体体系的收敛性需另行评估。

```bash
smj plan --config demo/siesta-au111/smj.yaml
smj preflight --config demo/siesta-au111/smj.yaml
```

示例默认 `dry-run`。实际提交时，在本次运行的配置中设置唯一的 `run.name`、`run.mode: slurm-ssh` 及目标集群资源，再执行 `smj preflight --config <配置路径>` 和 `smj run --config <配置路径>`。远端作业按阶段放在 `~/smj-runs/<run.name>/`。完成后用 `smj report --config <配置路径>` 查看结果。需要复用电极时，将 `siesta.electrode_reuse` 指向已采集的本地电极阶段目录。只改变横向 $k$ 点、不改变器件几何时，用 `siesta.reuse_relax_from` 指向已采集的 `siesta_junction_relax` 目录（或 run 根目录），跳过重复弛豫；复用的来源会写入 `relax.json` 的 `reused_from`，该几何并未在新 $k$ 网格上重新弛豫。只改变 TBtrans 横向 $k$ 点时，再用 `siesta.reuse_scf_from` 指向已采集的 `transiesta_scf` 目录（或 run 根目录），复用已收敛的器件 SCF 与 `device.TS.HSX`，只重建 TBtrans 输入；复用前核对自旋、结几何、接触和电极 HSX 摘要，来源写入 `scf.json` 的 `reused_from`。

## 一、入口与接触模型

由 `transport.backend: transiesta` 选择整条电子输运路线。选择后，分子优化、周期电极、散射区弛豫均使用 SIESTA。已有项目的 `molecule.opt_engine` 仅选择首段优化程序，`electrode.tip_direction` 仅定义针尖放置方向。读取旧配置时继续按原路线解释这两个字段。新路线沿用 `molecule.xyz`、电荷、多重度和左右锚定原子的表达方式。

以下是**接触配置片段**。该例选择两侧平坦 Au(111) 的 fcc 空位。位点只用于说明接口，实际值由体系协议指定。

```yaml
transport:
  backend: transiesta
siesta:
  contact:
    left:  {motif: flat, site: fcc}
    right: {motif: flat, site: fcc}
```

| 参数 | 构建器应执行的操作 |
|---|---|
| 左右接触的 `motif` | 两侧分别默认为 `flat`，即分子直接与 Au(111) 最外层结合。可选 `adatom`（一个额外 Au）、`trimer`（同层三个 Au 组成紧密三角形）、`pyramid`（三原子底层加一个顶端 Au）。左右可不同，每个运行只生成这一对构型。 |
| 左右接触的 `site` | 平面省略位点时，锚点从顶位 `top` 开始弛豫。可显式选择 `bridge`、`fcc` 或 `hcp`。省略整个 `siesta.contact` 时两侧均从 `flat/top` 开始。单 Au 和金字塔的局部位点为 `apex`，三原子面为 `center`。最终配位及位点迁移随弛豫坐标记录。 |
| 分子与接触的初始定位 | 使用左右锚点的稳定原子编号、分子取向、两端位点和电极间距生成一次初始结构。间距以两侧朝向分子的最外完整 Au 晶面为参考，单位为 Å。额外针尖原子的高度由各自金层向间隙内计。协议需给出间距或确定它的几何规则，并注明初始锚点高度或定位规则。两端条件不相容时报告几何冲突。 |
| 原子自由度 | 分子和两侧全部针尖原子默认可动。每侧可用 `movable_tip_atoms` 选择可动针尖原子，以该侧模板的 1 起算编号表示，金字塔底层为 1–3、顶端为 4。近平面处可移动的 Au 层数由 `siesta.electrode.movable_layers` 指定。连接半无限电极的匹配层固定在电极晶格位置。归档固定／可动原子编号、方向约束和最终层间距。 |

平面形貌本身不能确定结合位点。Strange 等在同一套 Au(111) 平面电极上，对苯二硫醇盐选 fcc 空位，对联吡啶选顶位。Montes 与 Vázquez 则在含金针尖的完整苯二胺结中，同时弛豫分子和针尖。以上结果给出了接触模板的物理先例。特定分子的生产位点、间距和可动层应记录在该次运行的协议中。[平面接触原文，第 VI–VII 节](https://backend.orbit.dtu.dk/ws/files/4803303/Strange.pdf) · [针尖接触原文，第 2 节](https://www.mdpi.com/2076-3417/11/2/802)

## 二、六个阶段及交付条件

| 阶段目录 | 输入与计算 | 交给下游的产物与判据 |
|---|---|---|
| ① 优化分子 `molecule_opt` | 从 XYZ、指定电荷及自旋态生成孤立分子 SIESTA 输入。记录边界条件、超胞及镜像处理，特别注明带电分子的处理。 | 优化后的 `opt.xyz`、原始编号与锚点映射、SCF 和力收敛记录。分别检查电子收敛、几何停止原因和最终自旋。 |
| ② 准备周期 Au 电极 `siesta_electrode` | 按 Au(111) 面内超胞和输运轴生成周期 Au 晶胞，保留正确的 ABC 堆垛。沿输运方向的电极重复单元应足够长，使矩阵耦合满足最近邻主层条件。运行 `siesta --electrode electrode.fdf` 或读取匹配的已收敛结果。 | 电极 FDF、包含哈密顿量和重叠矩阵的 HSX、电极费米能级、晶格/原子顺序及来源记录。对称电极可共用同一份结果，在器件两侧分别声明半无限延伸方向。 |
| ③ 组装并弛豫散射区 `siesta_junction_relax` | 将①的分子接到与②相容的显式左右 Au 层，按左右参数在此时添加针尖。用常规 SIESTA 在固定晶胞中做受约束优化。保存沿输运方向的超胞闭合方式，核查外侧金层在边界处的堆垛及间距。 | 初始/最终坐标及晶胞、约束、最终可动自由度最大力、锚点与近邻 Au 的编号及距离、实际配位和电极匹配结果。接触断开、重叠或匹配失败须标出。位点迁移保留初始与最终描述。 |
| ④ 零偏压开放边界自洽 `transiesta_scf` | 将③的最终散射区和②的电极接入 TranSIESTA，令左右电极化学势相同。运行中先获得周期体系初猜，再完成开放边界 NEGF 自洽。 | 保存收敛后的器件 `<label>.TS.HSX`、FDF、日志、共同化学势及必要的重启文件。验收开放边界 SCF、检查电荷偏差和金层屏蔽证据。只有初始周期 SCF 收敛时，本阶段未完成。 |
| ⑤ 计算透射谱 `tbtrans_te` | TBtrans 读取④的 `*.TS.HSX` 及②的电极文件，在指定能窗、能量网格和横向 $k$ 点上计算左右电极间透射。 | 保存原始 TBT NetCDF 输出及标准化 `transmission.tsv`，附电极顺序、横向权重、自旋通道、单位、费米能级与上下游文件摘要。同一份数据只做一次 $k$ 平均。 |
| ⑥ 线性电导 `junction_analyze` | 读取⑤的标准化谱和温度，按下节约定积分。此步在本地执行。 | `results.json` 和透射图。报告给出温度、$G$（S）、$G/G_0$、自旋约定，并可追溯到③的最终结构及实际左右接触。 |

②的电极计算与①的分子坐标独立。③同时依赖①、②，④同时依赖②、③，⑤同时依赖②、④。此依赖关系允许不同分子复用同一电极。电极复用须比较已解析的电极输入及程序版本，包括晶格、横向超胞、主层、原子顺序、Au 赝势内容摘要、基组、泛函、相对论处理、自旋、网格、展宽和电极 $k$ 点。复用还需验证文件完整且来源计算已收敛。改变局部针尖形状本身不会改变周期电极。相关 FDF 设置和两类器件哈密顿量见 [SIESTA 5.4 手册](https://docs.siesta-project.org/projects/siesta/en/5.4/reference/siesta.html)。

## 三、科学与数据约定

- **几何和接触化学。** 记录锚点的元素、原始编号、质子化状态和组装时移除的原子。左右锚点在去氢、重排和输出时都有可追踪的编号映射。分子电荷及多重度用于①。接入金电极后的电子占据由开放体系决定，另记器件自旋模式、初始磁矩和最终磁矩。项目的 `pin_contact` 与本路线的电极边界层固定分别处理。
- **几何匹配与电子屏蔽。** ③完成后，逐侧核对横向晶格、金层堆垛、电极块内的原子映射、相对坐标和半无限方向。坐标比较允许整体平移。向④提供符合 TranSIESTA 要求的电极块排列。匹配解决边界坐标问题，显式 Au 层厚度决定接触扰动到达边界时衰减多少。定量解释时注明金层厚度、横向超胞与 $k$ 点的收敛证据，缺少证据时标明未验证。[TranSIESTA 电极与散射区规范](https://docs.siesta-project.org/projects/siesta/en/5.4/reference/siesta.html)
- **电子结构参数。** 每次保存赝势来源与摘要、各元素 PAO 基组、实空间网格截断、交换关联泛函、色散、自旋处理、电子展宽、SCF/力停止阈值和各阶段 $k$ 网格。电极与器件共享相容的 Au 哈密顿量设置。电极沿半无限方向的采样与器件的横向采样分别记录。基组、阈值、网格及表面层数由体系协议给定。
- **数值收敛判据。** 横向 $k$ 点：固定 ③ 的弛豫几何，把横向超胞从 3×3 加密到 5×5（必要时 7×7），比较费米能级处的 $G/G_0$；相邻网格的相对变化小于 1% 记为通过。改变横向采样必须重建电极；③ 的几何通过 `siesta.reuse_relax_from` 复用，并在 `relax.json` 的 `reused_from` 中记录来源，因此报告须注明几何并未在该 $k$ 网格上重新弛豫。只加密 TBtrans 的横向 $k$ 点时，④ 的 SCF 通过 `siesta.reuse_scf_from` 复用，`scf.json` 的 `reused_from` 记录来源。屏蔽：④ 对每个 Au 层取 Mulliken 平均电荷，以电极中间体相层为参考；最外两层 $|\Delta q|\le 0.05\,e$ 且电极体相层 spread $\le 0.05\,e$ 记为通过。任一项缺失或不满足时保留 `inconclusive`/`failed`，不得用单点结果替代收敛证据。
- **谱的能量与通道。** 定义 $x=E-E_F$，单位 eV。记录原始文件或读取接口给出的单位和参考点，再转换一次。若原始输出已相对共同化学势，只换所需单位。每个物理自旋通道输出无量纲 $T_s(x)=\sum_k w_k T_{LR,s}(x,k)$，其中 $\sum_k w_k=1$。文件若已给加权平均则直接取用。对共线自旋逐通道核对能量、权重和来源。自旋轨道耦合／非共线数据需独立的通道约定，不能直接套用两列共线公式。[TBtrans 5.4 手册](https://docs.siesta-project.org/projects/siesta/en/5.4/reference/tbtrans.html)

令 $G_0=2e^2/h$，$e$ 为元电荷的正值，$T_{\rm el}$ 为计算电导所用的温度。用每个自旋通道只计一次的形式计算

$$
G(T_{\rm el})=\frac{e^2}{h}\sum_s\int T_s(x)
\left[-\frac{\partial f(x,T_{\rm el})}{\partial x}\right]\mathrm dx .
$$

无磁性、自旋简并且谱按单自旋给出时，两个自旋贡献相同，零温得到 $G/G_0=T(E_F)$。共线自旋分辨计算在零温得到 $G/G_0=[T_\uparrow(E_F)+T_\downarrow(E_F)]/2$。零温取费米能级处的值。网格跨过零点时记录所用插值。有限温度核对费米窗覆盖及积分网格分辨率。记录输运分析温度与 DFT 的占据展宽。已有 Landauer 代码可复用其积分与自旋归一化逻辑，应为 SIESTA 的谱列、单位与零温分支建立明确适配。[项目电导积分](../src/smj/junction/landauer.py) · [项目共线自旋口径](../src/smj/landauer_spin.py)

## 四、接入 AutoSMJ 与验收

1. **路线选择。** 让配置、阶段列表、依赖解析、运行状态、远端回取、预检和报告共同读取选定的电子路线。`smj run --dry-run`、单阶段执行、分段运行和恢复使用同一阶段表。旧运行记录按已有 AIMS 约定解析。检查点应核对路线及输入摘要，变更分子或接触仅使依赖它的结果失效。[阶段与状态](../src/smj/state.py) · [执行器](../src/smj/runner.py) · [报告](../src/smj/report.py)
2. **集群运行。** 以本次已核对的 gpu1 模块 `siesta/5.4.2-gpu-netcdf` 为目标环境。预检程序版本、NetCDF 支持、各元素赝势可读性及 Slurm 资源与模块要求。作业使用站点 MPI 启动方式和模块规定的栈设置，工作目录统一为 `$HOME/smj-runs/<run.name>/<阶段名>`。重试记录作业号、输入摘要和取回文件，避免旧轮次产物满足新轮次的验收。
3. **离线验收。** 用构造坐标验证平面模型额外 Au 数为零，以及单原子、三原子、四原子金字塔分别增加 1、3、4 个 Au。非对称配置逐侧核对。验证固定匹配层、锚点重编号、接触模板和位点迁移记录。损坏电极文件、电极错配、仅有周期 SCF 结果、丢失自旋通道均应定位到出错阶段。以常数透射谱验算：自旋简并单通道透射为 1 时 $G/G_0=1$。共线两通道为 1 和 0 时 $G/G_0=0.5$。再用具有非对称峰的谱验证能量参考点及 $k$ 权重。
4. **端到端验收。** 用用户点名的一个体系和一种接触模型贯通六步，检查能从结果追溯到收敛日志、两份电极引用、最终结构和原始透射文件。完成一次运行支持执行链验收。材料电导的定量判断另需该体系的数值收敛及接触证据。未获指定时只做离线验收，每次生产仅执行所选模型，物理证据不足时报告 `inconclusive`。2026-11-27 的 bpy/ppd 两例已满足执行链验收（见[验证记录](validation-siesta-2026-11-27.md)）；2026-11-28 的加密运行补上了横向 k 与屏蔽证据：bpy 未收敛（判定 `failed`），ppd 的 `G/G0` 在 1% 内稳定（判定 `passed`），两例屏蔽均 `passed`（见[k 点验证记录](validation-siesta-kconv-2026-11-28.md)）。`passed` 只覆盖数值判据，不构成材料电导的实验有效性验收。
5. **收敛证据汇总。** 对同一体系的两个已采集运行执行 `smj siesta-kconv BASE REFINED --json-out <run>/kconv.json`，把 $G/G_0$ 的相对变化、费米能级差和是否通过写入报告目录。`smj report` 与 `smj review` 只有在 `screening` 与 `kconv` 两项证据都通过时才输出 `passed`；证据缺失仍为 `inconclusive`。数值判据通过只说明该模型内部收敛，不构成实验可观测量的有效性证明。若同时做了 SCF 密度 k 收敛（3×3→5×5）和 TBtrans k 收敛（5×5→7×7），`kconv.json` 取较差的一组写入 run 根目录，另一组保留在验证记录中；报告的判定必须由较弱证据决定。
