### R1（P1-1）热窗覆盖判据：把"窗口跨零"升级为"窗口覆盖费米权重"

**证据**：见 §0 表；覆盖权重 0.234，解析差异 4.3 倍（G）与符号反转（S）。

**根因**：`src/smj/junction/criteria.py:441` `evaluate_run_criteria` 的窗口判据只查 `lo <= 0 <= hi`（`:475-485`），没有任何权重覆盖量；`analyze_te`（`src/smj/junction/landauer.py:78`）也不知道窗口是否截断。

**改法**：

1. `src/smj/junction/landauer.py` 新增两个纯函数，`analyze_te` 结果追加一个键（**只增不改**）：

```python
def fermi(e_ev: float, temperature: float) -> float: ...   # 1/(1+exp(e/kBT))

def thermal_window(rows, temperature: float) -> dict:
    """窗口对费米导数权重的覆盖: f(E_min)-f(E_max), 端点以 kBT 为单位。"""
    # -> {"e_min_ev","e_max_ev","kbt_ev","lower_kbt","upper_kbt","coverage"}
```

`analyze_te(...)` 返回新增 `"thermal_window": thermal_window(rows, temperature)`；既有键（`L0/L1/L2/S/k_e/ZT/...`）一个不动，保证 `gen_demo_reference.py --check` 与 4 份 demo 锚点不受影响。

2. `src/smj/junction/criteria.py` 注册新判据（放在 `te_window_covers_efermi` 之后）：

```python
{'name': 'te_thermal_window_coverage', 'kind': 'physical', 'gate': 'error',
 'implemented': True, 'band': [MIN_THERMAL_COVERAGE, None], 'source': None,
 'note': '2026-11-20 复审 P1-1: 窗口必须覆盖足够费米导数权重; 阈值 0.95 是数值约定'
         '(≈±3.66 kBT), 非文献量; 无源故入 KNOWN_GAPS'}
```

并把 `KNOWN_GAPS` 扩为 `frozenset({'k_e_zt_order', 'te_thermal_window_coverage'})`（严格说 `te_window_covers_efermi` 也欠登记，见 §6 可选项）。

3. `evaluate_run_criteria` 新增一条 check（在跨零判据之后）：

```python
tw = res.get('thermal_window') or {}
cov = tw.get('coverage')
ok = cov is not None and cov >= MIN_THERMAL_COVERAGE
checks.append(_check(
    'te_thermal_window_coverage', round(cov, 6) if cov is not None else None, ok,
    'T=%.0f K, kBT=%.4f eV; 窗 [%+.4f,%+.4f] eV = [%+.2f,%+.2f] kBT; 覆盖 %.4f'
    % (temperature, tw.get('kbt_ev', float('nan')), tw.get('e_min_ev', float('nan')),
       tw.get('e_max_ev', float('nan')), tw.get('lower_kbt', float('nan')),
       tw.get('upper_kbt', float('nan')), cov if cov is not None else float('nan')),
    missing=not ok))          # 证据不足 -> inconclusive, 不判 failed
```

`MIN_THERMAL_COVERAGE = 0.95` 定义在 `criteria.py` 常量区，注释写清 0.95 对应 ±3.66 kBT（300 K 约 ±0.095 eV）。

4. 报告层透出：`src/smj/report.py` 的 `_TRANSPORT_KEYS` 增加 `"thermal_window"`；`render_report` 的输运表加一行"费米窗覆盖（%/kBT 端点/温度）"。判定若为 `inconclusive` 且 `missing_evidence_criteria` 含该名，报告措辞沿用既有"无法判定 + 须补数据"。

**测试**（`tests/test_verdict_gates.py` 追加或 `tests/test_te_window_coverage.py` 新建）：
- 报告第 1 条断言：200 点常数窄窗 → `physics_verdict != "passed"`，且 `missing_evidence_criteria` 含 `te_thermal_window_coverage`；
- 宽窗解析对照：`T(E)=0.25`、`E∈[-0.5,+0.5]` → `G/G0≈0.25`（±2%）、`S≈0`（±2 µV/K）；
- 端点换算：`lower_kbt==e_min/kbt`、`coverage==fermi(E_min)-fermi(E_max)`（1e-12）；
- 既有 `tests/test_verdict_gates.py`、`tests/test_open_shell_gates.py` 不回归。

**验收**：第 1 条断言通过；52 份现有 `TE.dat` 的 `coverage` 全部 ≥0.9999，判定无翻转；`gen_demo_reference.py --check` 仍绿。

### R7（P2-7）工程/物理/警告分账

**证据**：物理失败把 manifest `engineering` 拉成 False；`warnings` 恒 0。

**根因**：`src/smj/verdict.py:62-85`——`errors` 统计全部 error 级失败（含物理），`warnings` 只匹配 `"warning"`，`engineering_passed = ... and errors == 0`。

**改法**：

```python
def _sev(c): return str(c.get("severity") or "").lower()

failed = [c for c in checks if not c.get("passed") and _applicable(c)]
warnings   = sum(1 for c in failed if _sev(c) in ("warn", "warning"))
eng_errs   = [c for c in failed if _sev(c) == "error" and c.get("name") not in PHYSICAL_NAMES]
phys_errs  = [c for c in failed if _sev(c) == "error" and c.get("name") in PHYSICAL_NAMES]
out["engineering_passed"] = not eng_errs            # 只由工程错误决定
out["errors"]             = len(eng_errs) + len(phys_errs)   # 保持"总体"语义
out["passed"]             = out["errors"] == 0
out["warnings"]           = warnings
out["engineering_errors"] = len(eng_errs)
out["physics_failures"]   = len(phys_errs)
```

1. `manifest["verdict"]` 的键元组加入 `engineering_errors/physics_failures`（`report.py:566`）；`render_report` 工程行附 `(工程错误 N, 物理失败 M, 警告 K)`。
2. `src/smj/junction/validate.py:166-167` 只改注释：`passed` 是**总体**（含 error 级物理判据），`engineering_passed` 才是工程口径——**行为不动**，否则 `src/smj/review.py:323,330` 与 `src/smj/preflight.py:326` 的门控会静默放过物理失败。
3. `apply_completeness` docstring 同步改写。

**测试**：报告第 6、7 条断言；`apply_completeness` 单测：物理失败 → `engineering_passed=True` 且 `physics_failures=1`、`engineering_errors=0`；`severity="warn"` 计入 `warnings`；`run_incomplete` 仍使 `engineering_passed=False`、`errors==1`（既有断言不变）。

**风险**：报告里"工程判定"会从 False 变 True——修复本意，CHANGELOG 必须写清；既有 run 重跑 `smj report` 会出现这一变化。
