### 2.1 证据与根因

- 反例：常数 `T=0.25`、300 K、12 点（−1.065..+1.135 eV，步长 0.2 eV）→ `L0=0.1443467064701852`、`S=+169.253 µV/K`、`coverage=1.0`、`physics_verdict=passed`；同窗 1101 点 → `L0=0.25`、`S≈0`。
- `src/smj/junction/criteria.py:500-531` 只有两条窗口判据：`te_window_covers_efermi`（跨 0）与 `te_thermal_window_coverage`（端点 `f(E_min)−f(E_max)`）。二者都只看**端点**，与网格密度无关。
- `src/smj/junction/landauer.py:91 minus_fermi_derivative` 给出权重 `w(E)`；`analyze_te`（`:130` 起）直接在实际网格上 `trapz`（`:50`）。300 K 时 `w` 的峰宽约 kBT=25.9 meV，步长 200 meV 时整个费米窗只剩 1 个采样点，梯形求积把权重积分低估 42%，且一阶矩因网格不对称变成 −1.96 kBT → 虚假 Seebeck。
- 归因：**证据不足**（网格分辨不了费米窗），不是物理否证。

```python
def fermi_quadrature(rows, temperature=300.0):
    """费米窗权重在实际网格上的求积充分性（与端点覆盖互补）。"""
    e = [r[1] for r in rows]            # 调用方保证已升序
    kbt = KB_EV_PER_K * temperature
    w = [minus_fermi_derivative(x, temperature) for x in e]
    weight_integral = abs(trapz(w, e))
    exact = fermi(e[-1], temperature) - fermi(e[0], temperature)   # 精确覆盖
    ratio = weight_integral / exact if exact else 0.0
    moment_ev = abs(trapz([x * y for x, y in zip(e, w)], e)) / weight_integral
    win = [x for x in e if abs(x) <= FERMI_WINDOW_KBT * kbt]
    steps = [b - a for a, b in zip(win, win[1:])]
    return {
        "kbt_ev": kbt,
        "weight_integral": weight_integral,
        "exact_coverage": exact,
        "ratio": ratio,
        "first_moment_kbt": moment_ev / kbt,
        "points_in_window": len(win),
        "min_step_in_window_ev": min(steps) if steps else None,
    }
```

## 5. R4 逐切片比较 + 空指标闸门

### 5.1 证据与根因

- `scripts/scan_convergence.py:197-231 compare_axis`：每个轴值只取**第一条**匹配记录（`:200-204 break`），于是 2×2 只比较“固定切片”（B=b₁ 平面 / A=a₁ 行），第四点 20 vs 10 永不进比较 → 两条轴都 `converged`。
- `:211-218`：双方都缺的指标 `continue`，`worst` 保持 0.0 → 全空指标判 `converged`。

### 5.2 改法

```python
def compare_axis(axis, rows, tol):
    others = [k for k in row_axis_keys(rows) if k != axis["key"]]
    slices = group_rows(rows, others)          # key = 其余轴的取值元组
    changes, worsts = [], []
    for slice_key, group in slices.items():
        ordered = [r for value in axis["values"] for r in group
                   if r["values"].get(axis["key"]) == value]   # 允许 0/多 条，重复要报
        for prev, nxt in zip(ordered, ordered[1:]):
            comparable = [m for m in METRICS
                          if prev["metrics"]["values"].get(m) is not None
                          and nxt["metrics"]["values"].get(m) is not None]
            if prev["metrics"]["status"] != "ok" or nxt["metrics"]["status"] != "ok":
                changes.append({"slice": slice_key, "from": ..., "to": ...,
                                "status": "missing"})
                continue
            if not comparable:
                changes.append({"slice": slice_key, "from": ..., "to": ...,
                                "status": "incomparable"})
                continue
            worst = max(_relative(float(nxt["metrics"]["values"][m]),
                                  float(prev["metrics"]["values"][m]))
                        for m in comparable)
            changes.append({"slice": slice_key, "from": ..., "to": ...,
                            "worst_relative_change": worst,
                            "converged": worst < tol,
                            "metrics": comparable})
            worsts.append(worst)
    # verdict 优先级: insufficient (<2 档) > incomplete (missing/incomparable) >
    #                converged (所有切片 worst<tol) > not-converged
```

## 7. R6 PDOS 占据表配对

### 7.1 证据与根因

- 末次占据 `[2,0]` 时 +0.2 eV 权重 0；前面加一轮 `[1,1]` 后该点变 **39.894**。
- `src/smj/pdos.py:362-399 parse_occupations`：把所有 `State Occupation` 表收进 `tables`，然后取“最后两张等长表”当 α/β：

```python
same = [t for t in tables if len(t) == len(tables[-1])]
if len(same) >= 2:
    return {..., "alpha": same[-2], "beta": same[-1]}
return {..., "alpha": tables[-1], "beta": None}
```

  闭壳层每轮 SCF 迭代都打一张同长度表，两轮就被误读成 α/β；`pdos.py:532-548` 再按索引把 `occupation` 乘进态权重，于是上一轮的 `[1,1]` 被当成 α。

### 7.2 改法

- `parse_occupations(aims_out, *, spin_polarized: bool | None = None)`：
  - `spin_polarized is True`：取最后两张**等长**表作 α/β（仍是“末次迭代的 α 后 β”），并返回 `alpha_size`/`beta_size`；
  - `spin_polarized is False`：只取最后一张表作 `alpha`，`beta=None`（附 `note`：“闭壳层，只取末次完整占据表”）；
  - `None`（未知）：保持旧行为但加 `inferred=True` 标记，供调用方决定是否信任。
- `analyze_pdos` 调 `parse_occupations` 时传 `spin_polarized = "beta" in channels`（`_channel_files` 已给出 `alpha`/`beta`/`mos`）。
- 态数核对：当 `table` 存在且 `len(table) != states`（该通道 `_scan_states` 的态数）→ `PdosError("占据表 %d 个态与 %s 的 %d 个本征态不一致：…")`，不静默按索引截断。
- note 文案改为“占据数取自 … 的 State Occupation 表（共 N 张；闭壳层取末次，开壳层取末次 α/β）”。
